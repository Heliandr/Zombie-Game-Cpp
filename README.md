# COVID 2020 — Console Zombie Survival Game

A small console-based zombie survival game I developed in C++ back in 2021 as one of my earliest programming projects.

The game takes place in a simple ASCII environment where the player must survive waves of zombies, collect vaccines and ammo, upgrade weapons, and reach the next level without getting caught.

As the levels progress, the number of zombies increases and surviving becomes more difficult. Zombies actively chase the player using a simple movement/chasing logic rather than moving completely randomly.

The game includes 20 levels, upgrade mechanics, directional shooting controls, ammo management, health tracking, and collectible items — all implemented in a text-based environment using pure C++.

## Features
